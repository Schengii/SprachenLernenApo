# Lingua viva – Offline-App (PWA)

1. Neues GitHub-Repo anlegen (z. B. `lingua-viva`, public – Pages ist bei privaten Repos nur mit Bezahlplan möglich).
2. Den Inhalt dieses Ordners (index.html, manifest.webmanifest, sw.js, Ordner icons) ins Repo-Root hochladen.
3. Repo → Settings → Pages → Branch `main`, Ordner `/ (root)` → Save.
4. Nach 1–2 Minuten: `https://<dein-name>.github.io/lingua-viva/` am Android-Handy in Chrome öffnen, einmal komplett laden.
5. Chrome-Menü ⋮ → „App installieren“ / „Zum Startbildschirm“. Danach läuft sie auch ohne Internet.
6. Lernstand übernehmen: in der Claude-Version „Datenschutz & meine Daten“ → Export, in der neuen App → Import.
7. Im Offline-Betrieb: Startseite → „Offline nutzen“ → vorab Lektionen laden (solange online, nur in der Claude-Version möglich, da KI nötig).

Hinweis: KI-Funktionen (Tutor, neue Lektionen, Schreiben, Übersetzer) gibt es nur in der Claude-Ansicht.
